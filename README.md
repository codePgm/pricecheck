# 메이플스토리 아이템 가격 검증 프로그램

OCR로 추출한 메이플스토리 아이템 가격 데이터를 AI가 자동으로 검증하고 오류를 수정하는 프로그램입니다.

## 🌟 주요 기능

- ✅ **완전 자동화**: 클릭 한 번으로 모든 검증 완료
- 🤖 **AI 기반 검증**: Google Gemini API로 이미지 직접 분석
- 🎯 **스마트 필터링**: 의심 항목만 AI로 확인하여 시간/비용 절약
- 💾 **자동 백업**: 원본 파일 안전하게 보관
- 📊 **상세 리포트**: 검증 결과를 보기 쉽게 정리
- 🎨 **시각적 표시**: 수정된 셀을 노란색으로 하이라이트

## 📋 필수 요구사항

- Python 3.8 이상
- Google Gemini API 키 (무료)
- Windows / Mac / Linux

## 🚀 설치 방법

### 1. Python 설치 확인

```bash
python --version
```

Python이 설치되어 있지 않다면 [python.org](https://www.python.org/downloads/)에서 다운로드하세요.

### 2. 프로그램 파일 다운로드

모든 파일을 하나의 폴더에 저장하세요:
- main.py
- config.py
- excel_handler.py
- gemini_checker.py
- validator.py
- report_generator.py
- requirements.txt

### 3. 필요한 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 4. Google Gemini API 키 발급

1. https://makersuite.google.com/app/apikey 접속
2. Google 계정으로 로그인
3. "Create API Key" 클릭
4. API 키 복사

**무료 할당량**: 하루 1500회까지 무료 (충분함!)

### 5. 설정 파일 수정

`config.py` 파일을 열어서 다음 항목들을 수정하세요:

```python
# 기본 경로
BASE_IMAGE_PATH = r"E:\code\ocrPCmaple\image"
BASE_OUTPUT_PATH = r"E:\code\ocrPCmaple\output"

# 서버 선택
SERVER = "scania"  # "scania" 또는 "cllrin"

# 날짜 (None이면 오늘 날짜 자동)
DATE = None

# 발급받은 Gemini API 키
GEMINI_API_KEY = "여기에_API키_붙여넣기"
```

**프로그램이 자동으로 생성하는 경로:**
- 이미지 폴더: `{BASE_IMAGE_PATH}\{SERVER}`
- 엑셀 파일: `{BASE_OUTPUT_PATH}\{DATE}\{SERVER}\최저가_{DATE}.xlsx`

**예시:**
- SERVER = "scania", DATE = "20260216"이면
- 이미지: `E:\code\ocrPCmaple\image\scania`
- 엑셀: `E:\code\ocrPCmaple\output\20260216\scania\최저가_20260216.xlsx`

## 💻 사용 방법

### 기본 사용법

1. 메이플스토리 아이템 가격 스크린샷 촬영
2. 이미지 파일명을 아이템 이름으로 설정

4. 프로그램 실행:

```bash

```

## ⚙️ 고급 설정

`config.py`에서 다양한 옵션을 조정할 수 있습니다:

### 검증 규칙 조정

```python
# AI 확신도 임계값 (0.0 ~ 1.0)
CONFIDENCE_THRESHOLD = 0.8

# 가격 차이 허용 범위 (%)
MAX_PRICE_DIFF_PERCENT = 10

# 자동 수정 여부
AUTO_FIX = True

# 백업 생성 여부
CREATE_BACKUP = True
```

### 시리즈별 가격 범위 설정

같은 시리즈 아이템끼리 가격 패턴을 비교하여 오류를 찾습니다:

```python
PRICE_RANGES = {
    "에테르넬": (90000000, 2500000000),      # 9천만 ~ 25억
    "미트라": (500000000, 600000000),        # 5억 ~ 6억
    "저주받은": (4600000000, 4900000000),    # 46억 ~ 49억
}
```

## 📁 출력 파일

프로그램 실행 후 생성되는 파일들:

1. **`최저가_YYYYMMDD_수정본.xlsx`**
   - 오류가 수정된 엑셀 파일
   - 수정된 셀은 노란색으로 표시

2. **`최저가_YYYYMMDD_backup.xlsx`**
   - 원본 엑셀 파일의 백업

3. **`검증리포트_YYYYMMDD.txt`**
   - 상세한 검증 결과 리포트
   - 어떤 아이템이 어떻게 수정되었는지 기록

## 🔍 작동 원리

### 1단계: 규칙 기반 필터링 (빠름, 무료)

다음 규칙으로 의심 항목을 자동 감지:

- ✓ 같은 시리즈 가격 패턴 비교
- ✓ 자릿수 일관성 체크
- ✓ 딱 떨어지는 숫자 (OCR 오류 가능성)
- ✓ 가격 범위 벗어남

**예시:**
- 미트라 시리즈: 모두 5억대 → 한 개만 5천만? **의심!**
- 에테르넬 글러브들: 18억, 19억, 19억 → 한 개만 1800만? **의심!**

### 2단계: AI 검증 (정확함)

의심 항목만 Google Gemini AI로 이미지 직접 분석:

1. 이미지를 AI에게 전송
2. AI가 화면의 가격 읽기
3. 엑셀 데이터와 비교
4. 차이가 크면 오류 확정

**67개 중 2~3개만 AI로 확인** → 빠르고 비용 절약!

## 🐛 문제 해결

### API 키 오류

```
ValueError: Gemini API 키가 설정되지 않았습니다.
```

**해결**: `config.py`에서 `GEMINI_API_KEY`를 올바르게 설정했는지 확인

### 파일을 찾을 수 없음

```
FileNotFoundError: 이미지 폴더를 찾을 수 없습니다
```

**해결**: `config.py`에서 경로를 확인하고 `r"경로"` 형식 사용

### 이미지 매칭 안 됨

**해결**: 이미지 파일명과 엑셀의 아이템 이름이 정확히 일치하는지 확인

### AI 분석 실패

**해결**: 
1. 인터넷 연결 확인
2. API 키가 유효한지 확인
3. 이미지 파일이 손상되지 않았는지 확인

## 📞 지원

문제가 발생하거나 질문이 있으면:

1. 리포트 파일(`검증리포트_YYYYMMDD.txt`) 확인
2. 에러 메시지 전체 복사
3. 어떤 파일에서 오류가 발생했는지 기록

## 📝 라이선스

이 프로그램은 개인적 사용을 위해 제공됩니다.

## 🎉 팁

1. **매일 실행**: 매일 OCR 후 바로 검증 실행하면 오류 누적 방지
